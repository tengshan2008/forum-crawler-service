# 前端显示重复帖子信息 - 实现总结

## 改进内容

现已在前端添加完整的重复帖子和采集失败信息显示，用户可以清楚看到采集结果的详细情况。

### 1️⃣ 任务列表页面改进

**文件**: `/frontend/src/pages/TaskList.js`

#### 新增"跳过/失败"列

在表格中添加了新的列显示统计：
```
[任务名] | [地址] | [类型] | [进度] | [采集数] | [跳过/失败] | [时间] | [操作]
```

**显示方式**：
- ✅ 采集成功：显示"5"（数字）
- ⚠️ 被跳过：显示 `3 跳过`（橙色标签）
- ❌ 采集失败：显示 `1 失败`（红色标签）
- ✓ 无问题：显示 "无"（灰色）

**示例**：
```
任务名: "采集论坛帖子"
采集: 5  |  跳过/失败: [3 跳过] [1 失败]
```

#### 展开行显示详细原因

点击表格左侧的"▶"可以展开查看详细信息：

```
┌─ 跳过/失败原因详情 (4)
│
│ [重复帖子]                          2024-01-01 12:00:00
│ 链接: https://t66y.com/htm_data/...
│ 说明: 帖子已存在
│
│ [网络错误]                          2024-01-01 12:01:00
│ 链接: https://t66y.com/htm_data/...
│ 说明: 无法获取页面内容
│
│ [解析失败]                          2024-01-01 12:02:00
│ 链接: https://t66y.com/htm_data/...
│ 说明: 解析帖子失败
└─
```

**原因分类**：
- 🟠 **重复帖子** (orange) - 帖子已存在于数据库
- 🔴 **网络错误** (red) - 无法获取页面内容
- 🟤 **解析失败** (volcano) - 提取内容失败
- 🟡 **更新检查失败** (gold) - 内容更新检查失败
- ⚪ **其他** (default) - 其他原因

### 2️⃣ 任务预览页面改进

**文件**: `/frontend/src/pages/PostPreview.js`

#### 采集统计面板

页面顶部新增统计卡片，一目了然展示采集结果：

```
┌─────────────────────────────────────┐
│         采集统计                     │
├─────────────────────────────────────┤
│  5         3 已跳过    1 采集失败  ✓ │
│  已采集                              │
│                                       │
│  跳过原因统计:                       │
│  [重复帖子: 2]  [网络错误: 1]       │
└─────────────────────────────────────┘
```

**四个核心指标**：
1. **已采集** (蓝色) - 本次新采集的帖子数
2. **已跳过** (橙色) - 因重复或其他原因跳过的帖子数
3. **采集失败** (红色) - 因网络或解析错误失败的帖子数
4. **状态** (绿色) - 任务当前状态

**跳过原因统计**：
快速看到各类跳过原因的数量分布，例如：
- 重复帖子: 2
- 网络错误: 1
- 解析失败: 0

## 代码实现

### TaskList.js 添加的内容

1. **新增列定义**：显示 skippedItems 和 failedItems
```javascript
{
  title: '跳过/失败',
  render: (_, record) => (
    <Space>
      {record.skippedItems > 0 && <Tag color="orange">{record.skippedItems} 跳过</Tag>}
      {record.failedItems > 0 && <Tag color="red">{record.failedItems} 失败</Tag>}
    </Space>
  ),
}
```

2. **表格展开行**：显示详细的跳过原因列表
```javascript
expandable={{
  expandedRowRender: (record) => {
    // 显示 skipReasons 数组中的每一项
    // 包含原因、链接、时间戳等信息
  },
  rowExpandable: (record) => record.skipReasons?.length > 0,
}}
```

3. **辅助函数**：
```javascript
const getReasonColor = (reason) => {
  // 根据原因类型返回对应的标签颜色
}

const getReasonLabel = (reason) => {
  // 将原因代码转换为中文描述
}
```

### PostPreview.js 添加的内容

1. **获取任务信息**：
```javascript
const fetchTaskInfo = async () => {
  const response = await fetch(`/api/tasks/${taskId}`);
  const result = await response.json();
  setTask(result.data);
}
```

2. **统计卡片**：
```javascript
<Card title="采集统计">
  <Row gutter={[16, 16]}>
    <Col><Statistic title="已采集" value={task.crawledItems} /></Col>
    <Col><Statistic title="已跳过" value={task.skippedItems} /></Col>
    <Col><Statistic title="采集失败" value={task.failedItems} /></Col>
  </Row>
</Card>
```

3. **跳过原因摘要**：
```javascript
{task.skipReasons && task.skipReasons.length > 0 && (
  <div>
    {/* 统计各类原因的数量 */}
    {Object.entries(
      task.skipReasons.reduce((acc, reason) => {
        acc[reason.reason] = (acc[reason.reason] || 0) + 1;
        return acc;
      }, {})
    ).map(([reason, count]) => (
      <Tag color={getReasonColor(reason)}>
        {getReasonLabel(reason)}: {count}
      </Tag>
    ))}
  </div>
)}
```
