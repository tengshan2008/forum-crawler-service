## 📋 功能验证

### 去重逻辑
- [x] 相同 URL、相同内容 → `duplicate`（跳过）
- [x] 不同 URL、相同内容 → `content_duplicate`（跳过）
- [x] 相同 URL、不同内容 → `shouldUpdate=True`（覆盖更新）
- [x] 全新帖子 → 保存为新帖子

### 数据库操作
