【快速启动】(5分钟)
================================================================================

1. 后端启动配置 (3行代码)
   编辑: backend/src/index.js
   在 connectDB() 之后添加监控初始化代码
   
2. 前端路由配置 (8行代码)
   编辑: frontend/src/App.js
   添加管理页面路由

3. 安装依赖
   $ cd frontend && npm install recharts

4. 启动服务
   $ docker-compose -f docker/docker-compose.dev.yml up -d

5. 访问管理
   http://localhost:3000/admin
   (需要 admin 权限)
